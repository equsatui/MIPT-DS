# MIPT-DS
Ряд заданий с предметами, связанных с DS на Физтехе.

Самое интересное - два крупных задания, по CV и NLP соответственно. Это CV-big_task.py и NLP-big_task.py

NLP:
1) Анализ тональности с экспериментами по моделям
2) Классификация запросов + способы дообучения на новых классах

CV: КАРТОГРАФИЯ И ДЕТЕКТИРОВАНИЕ ДОРОЖНЫХ ОБЪЕКТОВ - состоит из четырех частей
1) Сегментация дорог на спутниковых снимках 
2) Построение графа дорожной сети
3) Детекция объектов на дороге
4) Пайплайн применения модели детекции для анализа видео
